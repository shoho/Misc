# GR Look

iPhone で撮った写真を、RICOH GR IV っぽい落ち着いた色味に近づけるデモアプリです。ブラウザだけで動きます(サーバー不要、画像はどこにも送信されません)。

iPhone の写真は「眩しい」「彩度が高い」「HDR で妙に平板」になりがちなので、その逆をやります。

- **ハイライトを寝かせる** … 白飛び気味の空や壁をなだらかに圧縮
- **彩度を落とす** … 派手な赤・緑・青を GR らしい抑えたトーンに
- **ローカルコントラストを抜く** … iPhone の HDR 処理が作る「どこも明るい」感じを弱める
- **フィルムっぽい味付け** … 黒の浮き、スプリットトーン、粒状感、周辺光量落ち

## 使い方

`index.html` をブラウザで開くだけです。iPhone の Safari でも動きます。

```bash
# ローカルで開く
open gr4-look/index.html

# あるいは簡易サーバーで
cd gr4-look && python3 -m http.server 8000
# → http://localhost:8000
```

1. 「写真を開く」で写真を選ぶ(ドラッグ&ドロップ、クリップボードからの貼り付けも可)。手元に写真がなければ「サンプル」で試せます
2. 「イメージコントロール」からプリセットを選ぶ
3. 好みに合わせてスライダーを調整
4. 「書き出し」で JPEG を保存(iPhone では共有シートが出るので「画像を保存」)

画像を**長押し**すると元画像が見えます。「比較」を押すとスライダーで左右分割の比較ができます。

## プリセット

GR のイメージコントロールを参考にした近似です(リコー公式のプロファイルではありません)。

| プリセット | ねらい |
|---|---|
| スタンダード | 素直だけど眩しくない。まずはこれ |
| ポジフィルム調 | 締まった黒と深い色。GR らしい定番 |
| ネガフィルム調 | 柔らかくて少し褪せた、フィルムの記憶 |
| シネマ | ティール&オレンジ寄りの、映画の一コマ |
| ブリーチバイパス | 銀残し。色を抜いてコントラストを上げる |
| レトロ | 黄ばんだプリントみたいな温かさ |
| クロスプロセス | 転んだ色。緑がかった光と青い影 |
| ビビッド | 派手だけど iPhone とは違う派手さ |
| ハイコントラスト白黒 | ザラついた粒子と黒の量 |
| モノトーン | 素直な白黒 |
| ソフトモノトーン | 灰色が豊かな、やわらかい白黒 |

## 調整パラメータ

| 項目 | 何をするか |
|---|---|
| 露出 | 全体の明るさ(線形空間で EV 単位) |
| ハイライト圧縮 | 明部を膝(knee)より上でなだらかに圧縮。眩しさ対策の主役 |
| シャドウ | 暗部だけを持ち上げ / 沈める |
| コントラスト | S 字カーブ。白飛び・黒つぶれしにくい方式 |
| フェード(黒浮き) | 黒点を持ち上げてフィルムっぽく |
| ローカルコントラスト | マイナスで HDR 感を抜く。プラスで硬質に |
| 彩度 | 輝度を保ったまま彩度を増減 |
| 色温度 / 色かぶり | ホワイトバランスの微調整 |
| スプリットトーン強さ | プリセットが持つ「影の色・光の色」の効き具合 |
| シャープネス | アンシャープマスク |
| 粒状感 / 粒の大きさ | フィルムグレイン |
| 周辺光量落ち | 四隅を落とす |

## 仕組み

`app.js` の 1 本の WebGL フラグメントシェーダで全処理をしています。パイプラインはこの順番です。

1. シャープネス(表示空間)
2. sRGB → 線形
3. ホワイトバランス、露出
4. ローカルコントラスト(縮小→拡大で作った大半径ぼかしを土台に、ディテール成分を増減)
5. ハイライト圧縮(knee=0.4 より上を `t / (1 + k·t)` で圧縮)
6. 3×3 カラーマトリクス(プリセットごとの色のキャラクター)
7. 線形 → 表示空間
8. シャドウ、コントラスト(S 字)、フェード
9. 彩度 / モノクロ(チャンネルミックス付き)
10. スプリットトーン
11. 周辺光量落ち、粒状感

プレビューは長辺 1600px に縮小して表示し、書き出し時は元解像度(長辺 4096px またはブラウザの上限まで)で再レンダリングします。

プリセットを足したいときは `app.js` の `PRESETS` 配列に追加するだけです。`colorMatrix` と `shadowTint` / `highlightTint` がそのプリセットの「らしさ」の大部分を決めます。

## 制限

- HEIC は Safari 以外のブラウザでは開けません。iPhone の Safari から使うか、JPEG に変換してください
- iPhone の HDR 写真(ゲインマップ付き)は SDR 部分だけを処理します
- あくまで「それっぽく」する近似で、GR IV の実際の絵作りを再現するものではありません
